# ВерсияШаблона

## Описание

Кнопка формирует значение версии шаблона на основе последней даты изменения листов
из блока "Даты утверждения/изменения листов" (системный параметр **Дата изменения**).

Алгоритм:
1. Собирает все листы проекта.
2. Читает значение системного параметра `BuiltInParameter.SHEET_CURRENT_REVISION_DATE`
   (резервно ищет параметры "Дата изменения" и "Revision Date").
3. Находит максимальную корректную дату.
4. Преобразует дату в формат `vYYMMDD`.
   - Пример: `18.05.26` → `v260518`.
5. Записывает результат в общий параметр `GP_01_ВерсияШаблона`.

Если общий параметр не найден, выводится сообщение:

> Добавьте параметр GP_01_ВерсияШаблона в проект

## Используемые параметры

- Источник: системный параметр листа `Дата изменения`
  (`BuiltInParameter.SHEET_CURRENT_REVISION_DATE`).
- Назначение: общий параметр `GP_01_ВерсияШаблона`
  (GUID: `6e4772dc-dffd-487b-9e95-76c56f4a66aa`, тип: текст).

## Технические детали

- Все изменения выполняются в транзакции `Запись GP_01_ВерсияШаблона`.
- Основная точка записи: `Project Information`.
- Резервная запись: листы (если параметр привязан к категории листов).

## Зависимости

Внешних зависимостей нет.
Используются только `RevitAPI`, `RevitAPIUI`, `pyrevit`.
