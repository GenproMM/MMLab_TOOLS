# ВОР Валидатор

pyRevit-плагин для проверки параметров ведомости объёмов работ (ВОР) в моделях Revit.
Позволяет запускать настраиваемые наборы проверок для каждого раздела и проекта.

## Возможности

- **Разделы и проекты** — выберите раздел (АР, КР, ОВ, ВК и др.) и проект; каждому сочетанию соответствует свой набор скриптов
- **Управление скриптами** — включайте и отключайте отдельные проверки, добавляйте новые скрипты через кнопку «+»
- **Настройки скриптов** — каждый скрипт может иметь собственные параметры (категории для проверки, списки исключений и т.д.)
- **Импорт конфигураций** — переносите настройки между пользователями через JSON-файл
- **Устойчивость к перемещениям** — скрипты привязаны через уникальные ID, поэтому переименование или перемещение файлов не ломает конфигурацию

## Входящие скрипты

| Скрипт | Описание |
|--------|----------|
| Заполненность GP_01_Зона | Проверяет заполнение параметра зоны по категориям |
| Заполненность GP_01_Коды | Проверяет заполнение кодов единиц и видов работ |
| Загрузка параметров GP_01 | Загружает общие параметры GP_01 из файла на сетевом диске и привязывает к категориям Revit |

## Разработка новых скриптов

Плагин поддерживает создание собственных скриптов проверки. При работе с [Claude Code](https://docs.anthropic.com/en/docs/claude-code) доступны два навыка:

- **[$VorScriptCreator](./.claude/skills/VorScriptCreator/SKILL.md)** — генерация скриптов валидации: метаданные, контракт `run()`, схема настроек, работа с Revit API
- **[$VorUICreator](./.claude/skills/VorUICreator/SKILL.md)** — создание WPF-окон (настройки, результаты, диалоги) в дизайн-системе плагина

Каждый скрипт размещается в отдельной папке внутри `scripts/`:
```
scripts/
  Имя скрипта/
    Имя скрипта.py        # основной файл
    lib/                   # вспомогательные модули (опционально)
```

## Требования

- Revit 2024+
- [pyRevit](https://github.com/eirannejad/pyRevit)
- IronPython 2.7
