## Иконка

Положи рядом со `script.py` файл `icon.png` (PNG, примерно 96×96 px).
Без него pyRevit покажет кнопку без иконки — это не ошибка.

## Как использовать шаблон

1. Скопируй папку в `MM_LAB.extension/MM Lab.tab/<Панель>.panel/`.
2. Переименуй её в `<Имя кнопки>.pushbutton`.
3. Заполни все метки `TODO` в `script.py`, `bundle.yaml` и этом `README.md`.
4. Добавь имя кнопки (без суффикса `.pushbutton`) в `layout` файла
   `bundle.yaml` панели.
5. Сделай pyRevit Reload — кнопка появится на панели.

Или запусти команду `/mm-new-button` — она выполнит эти шаги за тебя.
