# Все кнопки extension покрыты отдельными заметками

- [[Кнопка ВОР_СсылкаНаЛист ускоряет выпуск ведомостей с привязкой к листам]]
- [[Кнопка Высота этажа стандартизирует расчет высотных параметров этажей]]
- [[Кнопка Кривые панели ускоряет обработку криволинейной геометрии панелей]]
- [[Кнопка Кривые панели (Импост) поддерживает специализированный сценарий импостов]]
- [[Кнопка Мокрые зоны помогает поддерживать корректную геометрию и параметры мокрых зон]]
- [[Кнопка Проверка зон снижает риск ошибок в зонировании проекта]]
- [[Кнопка Экспорт ПСО формирует выгрузку ПСО в Excel]]
- [[Кнопка Доп расход 0 автоматизирует расчет добавочного расхода для ИОС]]
- [[Кнопка Доп расход 1 расширяет расчет добавочного расхода для ИОС-сценариев]]
- [[Кнопка Замена CAD-геометрии переводит CAD-вставки в управляемую Revit-геометрию]]
- [[Кнопка Конфузор-Диффузор ускоряет подбор параметров переходных элементов]]
- [[Кнопка Приточный по классификации нормализует обработку приточных систем]]
- [[Кнопка Сброс потерь централизованно сбрасывает расчетные потери в ИОС]]
- [[Кнопка ВерсияШаблона удерживает единый контроль версий шаблона проекта]]

Связанные разделы:
- [[Тихие except блоки скрывают критические ошибки в ИОС-скриптах]]
- [[Кнопки pyRevit должны быть тонкими и выносить общую логику в модули]]
- [[Все изменения модели должны проходить через Transaction с rollback]]
