# 
Кнопка Доп расход 0 автоматизирует расчет добавочного расхода для ИОС

Панель: 
ИОС
Кнопка: 
Доп расход 0

Команда выполняет массовую обработку ИОС-элементов для сценария дополнительного расхода.

- [[Текущие приоритеты сосредоточены на надежности ИОС-скриптов]]
