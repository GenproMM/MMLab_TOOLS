# Все изменения модели должны проходить через Transaction с rollback

Любая запись в модель Revit должна происходить в транзакции, чтобы гарантировать атомарность и безопасный откат при ошибке.

Обоснование:
- Защита модели от частично примененных изменений
- Предсказуемое поведение в аварийных сценариях

Связанные утверждения:
- [[Интеграция с Revit API выполняется в процессе Revit]]
- [[Тихие except блоки скрывают критические ошибки в ИОС-скриптах]]
- [[Проект не использует отдельную БД и хранит данные в модели Revit]]
