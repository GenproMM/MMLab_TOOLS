# Кнопки pyRevit должны быть тонкими и выносить общую логику в модули

Паттерн снижает связанность UI-слоя и бизнес-логики, делает команды проще для поддержки и отладки.

Практическая структура:
- script.py как точка входа и orchestration
- Первая строка каждого script.py: `#! python3` для запуска через CPython-движок pyRevit (по настройкам Engines)
- Все script.py и shared-модули обязаны быть совместимы с выбранной в pyRevit версией CPython Engine (текущая конфигурация: CPython 3123, x64)
- Мультиверсионная поддержка Revit API обязательна для Revit 2020, 2022 и 2024
- Вызовы API с межверсионными различиями должны быть инкапсулированы в универсальные функции с проверкой версии активной Revit-сессии и выбором нужной реализации
- Общие вычисления и трансформации в отдельные модули
- Единый обработчик ошибок и формат сообщений пользователю
