# Тихие except блоки скрывают критические ошибки в ИОС-скриптах

Проблема:
- Перехват исключений без логирования приводит к ложному ощущению, что команда отработала корректно.

Симптомы:
- Пользователь не видит причину сбоя
- Сложно локализовать поломку на данных проекта

Базовое решение:
- Ловить типизированные исключения
- Писать понятное сообщение в pyRevit output и UI
- При критических ошибках откатывать Transaction

Связанные утверждения:
- [[Все изменения модели должны проходить через Transaction с rollback]]
- [[Кнопки pyRevit должны быть тонкими и выносить общую логику в модули]]
- [[Текущие приоритеты сосредоточены на надежности ИОС-скриптов]]
