# Сессия: обновление кнопки ПубликацияШаблона

## Работа

Обновлена кнопка **ПубликацияШаблона** в адаптированной копии (`MMLab.extension`) на основе изменений в исходнике (версия на `G:\...\LL.extension`, обновлена 01.09.2026 15:16).

### Ключевые изменения

1. **Функционал**: кнопка теперь публикует выбранный проект сразу в двух форматах
   - `.rvt` → `1_RVT` (очистка имени от суффикса пользователя, сохранение рабочих наборов)
   - `.rte` → `2_RTE/<год>` (очистка + маркер `RD_`, удаление рабочих наборов)

2. **Новое**: WinForms-диалог выбора из всех открытых проектов (вместо работы с активным документом)

3. **Новое**: временная копия создаётся в `%TEMP%`, а не в целевой папке

4. **Новое**: для `.rvt` — опция `WorksharingSaveAsOptions.SaveAsCentral`

5. **Адаптация под конвенцию MM LAB**:
   - Возвращён гейт версии через `revit_compat.require_supported_version`
   - Возвращён канонический lib-бутстрап
   - Год-подпапка `.rte` из версии Revit, а не хардкод
   - Импорты по одному имени
   - pythonnet 3.x overload-совместимость (`Font("...", 9.0, ...)`)

6. **Фильтр связей**: `get_eligible_documents` отсеивает загруженные RVT-связи (`IsLinked`)

7. **Обновлена документация**: README раскрывает новый функционал в 8 шагов, bundle.yaml обновлена на оба формата

### Проверка
