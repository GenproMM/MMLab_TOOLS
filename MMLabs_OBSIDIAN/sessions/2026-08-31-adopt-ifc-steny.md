# 2026-08-31: Приёмка кнопки IFC_Стены

## Итог
Принята и адаптирована кнопка классификации стен по МССК (четвёртая из семейства
IFC-классификации после Дверей, Окон и Перекрытий). Исходник переписан под конвенцию
MM LAB, целевые параметры изменены на `GP_01_КодКлассифМССК` / `GP_01_ИмяКлассифМССК`
по GUID, признак наружной стены — `WallType.Function` вместо LookupParameter.

**Коммит:** b0b9c1c «приёмка: кнопка IFC_Стены адаптирована под конвенцию MM LAB»
**Quick task:** 260831-wal (`.planning/quick/260831-wal-adopt-ifc-steny/`)

## Что изменено
- Шапка скрипта: `#! python3` + UTF-8 coding
- Русский docstring со строками Совместимость и Зависимости
- Опечатка `__autor__` → `__author__ = "GENPRO LAB"`
- `pyrevit.forms` заменён на явные импорты Autodesk/System и WinForms
- Оба `LookupParameter` со строковым литералом убраны:
  - `LookupParameter("GP_11_Группирование")` → `GP_01_ИмяКлассифМССК` по GUID
  - `LookupParameter("Наружная стена")` → `WallType.Function == WallFunction.Exterior`
- Восемь голых `except:` → `except Exception`
- Создан `bundle.yaml` и `README.md` по образцу соседних IFC-кнопок
- Зарегистрирована в layout панели АРХИТЕКТУРА (после IFC_Перекрытия)
- Добавлен канонический lib-бутстрап
- Транзакция по правилам: `Start()` перед `try`, `Commit()` в `try`, `RollBack()`+`raise` в `except`
- Гейт версии в начале `main(doc)`, doc передаётся аргументом вместо глобального
- Совместимость 2020/2022/2024: `convert_from_internal`, `element_id_value`

## Исправленные дефекты
1. **Цепное «заражение» этап 2:** флаг `added_new` сбрасывался раз за итерацию,
   а не на каждой стене — после первой зашивки перегородки и отделки в той же
   итерации не проверялись. Теперь на каждой стене, выход по первому совпадению.
2. **is_partition_wall ПРОВЕРКА 2:** мёртвая ветка `if not is_exterior_wall: return True`
   после лишних запросов помещений — упрощено до `return True` без запросов.
