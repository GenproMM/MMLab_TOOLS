# Проект не использует отдельную БД и хранит данные в модели Revit

В репозитории отсутствуют признаки отдельного слоя БД. Данные читаются и записываются напрямую через Revit API в элементы, параметры и транзакции модели.

Последствия:
- Источник истины находится в модели Revit
- Консистентность контролируется границами Transaction
- Стратегия миграций данных зависит от версий шаблонов и параметров

Связанные утверждения:
- [[Интеграция с Revit API выполняется в процессе Revit]]
- [[Все изменения модели должны проходить через Transaction с rollback]]
- [[Деплой выполняется через установку pyRevit extension в локальную среду]]
