# Архитектура построена вокруг pyRevit pushbutton-скриптов

Проект организован как pyRevit extension: вкладка содержит панели, панели содержат команды, а каждая команда исполняет свой script.py в контексте активного документа Revit.

Архитектурное требование исполнения: каждый entry-point файл script.py должен начинаться первой строкой `#! python3`, чтобы pyRevit запускал команду через CPython-движок в соответствии с настройками Engines.
Архитектурное требование совместимости: все скрипты extension и общие Python-модули должны корректно работать на версии CPython Engine, выбранной в pyRevit Engines (на текущей конфигурации: CPython 3123, x64).
Архитектурное требование мультиверсий Revit API: код должен поддерживать Revit 2020, 2022 и 2024.
Если метод, свойство или класс Revit API отличается между версиями, функция с таким вызовом должна быть универсальной: с проверкой версии активной сессии Revit и выбором корректной ветки выполнения.
Проверка версии должна выполняться централизованно (через helper/адаптер), а не дублироваться в каждой команде.
