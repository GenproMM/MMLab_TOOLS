# Нужно формализовать политику логирования ошибок в скриптах

Черновая идея:
- Запретить пустые except в продуктивном коде
- Ввести единый формат сообщений для пользователя и технического лога
- Для критичных операций требовать rollback и явный статус ошибки

Связанные утверждения:
- [[Тихие except блоки скрывают критические ошибки в ИОС-скриптах]]
- [[Все изменения модели должны проходить через Transaction с rollback]]
- [[Текущие приоритеты сосредоточены на надежности ИОС-скриптов]]
