# Summary: приёмка кнопки IFC_Перекрытия

Сторонний скрипт классификации перекрытий по МССК принят и адаптирован под
конвенцию MM LAB на панель **АРХИТЕКТУРА**. Кнопка `IFC_Перекрытия` даёт
выбрать типоразмеры перекрытий (фундаментные плиты исключены) и в одной
транзакции пишет всем их экземплярам `GP_01_КодКлассифМССК` = `ЭЛ 30 10 40`
и `GP_01_ИмяКлассифМССК` = «Перекрытие».

Приведено к конвенции: шапка (MM001–MM004), явные импорты вместо
`pyrevit.forms` + WinForms-диалог (MM008/MM012), параметры через
`revit_compat` (MM010), `bundle.yaml` + `README.md` (MM005/MM006),
канонический lib-бутстрап (MM014), fail-fast по версии (D-03),
транзакционный каркас с `RollBack()`+`raise` (правило 10), `doc`
параметром (правило 18), `element_id_value` для Revit 2024.
Кнопка зарегистрирована в layout панели после `IFC_Окна` (MM007).

По решению пользователя изменена цель записи: вместо «Комментарии» и
`GP_11_Группирование` — общие параметры `GP_01_*`, как в `IFC_Двери`
и `IFC_Окна`.

Строгий чекер по кнопке — exit 0. Общий прогон с baseline остаётся exit 1
из-за предсуществующего долга (`IFC_Стены` ещё не принята; `СНиП`,
`СНиП_ФОП25` не покрыты baseline) — к этой приёмке отношения не имеет.
