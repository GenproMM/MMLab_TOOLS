# Summary: приёмка кнопки ПубликацияШаблона

Сторонний скрипт публикации проекта в шаблон принят и адаптирован под
конвенцию MM LAB на панель **КООРДИНАЦИЯ**. Кнопка `ПубликацияШаблона`
экспортирует открытый проект `.rvt` в шаблон `.rte` в общую папку публикаций:
сохраняет проект, делает временную копию, открывает её фоном с отсоединением
от центральной модели, сохраняет как `.rte` и убирает за собой временные файлы
и папки бэкапов.

Приведено к конвенции: шапка с `#! python3` (MM001–MM004), `bundle.yaml` +
`README.md` (MM005/MM006), `print()` → `TaskDialog` (MM012) и верхнеуровневый
`try/except Exception` (правило 11), канонический lib-бутстрап (MM014),
fail-fast по версии (D-03), `doc`/`app` параметрами вместо модульного
`__revit__` (правило 18), явные `clr.AddReference`. Кнопка зарегистрирована
в layout панели после `ВерсияШаблона` (MM007). Транзакция не вводится
осознанно: `doc.Save()` и `SaveAs` Revit запрещает внутри транзакции.

По решению пользователя сняты две привязки к Revit 2024: год папки публикации
и маркер `Rxx` в имени файла теперь собираются из версии, которую вернул
`require_supported_version()` — ветвлений по версии в скрипте нет (D-01).
Третья правка поведения: `temp_doc.Close(False)` перенесён в `finally`, иначе
при падении `SaveAs` фоновый документ оставался открытым и блокировал
`_temp.rvt` до перезапуска Revit.

Строгий чекер по кнопке — exit 0. Общий прогон с baseline остаётся exit 1
из-за предсуществующего долга (`СНиП`, `СНиП_ФОП25` не покрыты baseline,
пришли коммитом `ccde781`) — к этой приёмке отношения не имеет, baseline
не правился.
