# Приёмка кнопки «Доп. расход 0»

## Task

Адаптация существующей кнопки ИОС.panel/Доп расход 0 под конвенцию MM LAB.

**Исходник:** физически уже лежит в репозитории, содержал нарушения MM003, MM004, MM006, MM014.

**Панель:** ИОС (воздуховодная сеть, BuiltInCategory.OST_DuctCurves и связанные).

**Имя:** Доп расход 0 (уже в layout панели).

## Adaptation summary

### MM003: UTF-8 BOM
- **Было:** файл начинался с BOM (EF BB BF).
- **Исправлено:** переписан в UTF-8 без BOM через Write tool.

### MM004: docstring
- **Было:** нет docstring со строками «Совместимость:» и «Зависимости:».
- **Исправлено:** добавлен русский docstring с обеими строками.

### MM006: README.md
- **Было:** файл не существовал.
- **Исправлено:** создан README с разделами Описание, Логика работы, Используемые параметры, Зависимости, Совместимость, Ограничения.

### MM014: lib-бутстрап
- **Было:** `SCRIPT_DIR`/`EXTENSION_ROOT`/`LIB_DIR`, `sys.path.append`.
- **Исправлено:** канонический блок `_SCRIPT_DIR`/`_EXTENSION_DIR`/`_LIB_DIR`, `sys.path.insert(0, ...)` (D-15).

### Правило 18: doc/uidoc — параметрами
- **Было:** `get_document` из `ios_common_helpers` читал `__revit__` внутри lib-модуля.
- **Исправлено:** логика обёрнута в `main(doc)` + `_entry()`; `__revit__`/`uidoc`/`doc` получаются в script.py и передаются параметром.

### Правило 9 / D-03: require_supported_version
- **Было:** не было гейта версии.
- **Исправлено:** добавлен `revit_compat.require_supported_version(COMMAND_NAME)` в начало `main()`.

### bundle.yaml и author
- **Было:** только русская локаль, author = «MM Lab».
- **Исправлено:** добавлена en_us локаль (title/tooltip), author = «GENPRO LAB» (по стандарту принятых кнопок).

## Результаты

- Кнопка адаптирована под конвенцию MM LAB.
- Строгий чекер (--strict): exit 0, 0 ошибок, 0 предупреждений.
- Запись удалена из baseline.json (units).
