Вызов:
```
py -3 tools/check_convention.py [PATHS...] [--all] [--strict] [--json] [--baseline PATH] [--write-baseline PATH] [--root PATH]
```

- `PATHS` — пути к папкам `*.pushbutton` ИЛИ к одиночным `*.py` (режим «сырого скрипта»: только правила уровня файла — MM000–MM004; в 03-03 добавятся MM008–MM012, MM014; структурные MM005–MM007, MM013 пропускаются).
- `--all` — обход `<root>/MM LAB.extension/MM Lab.tab/**/*.pushbutton` + проверка орфанов layout в tab- и panel-`bundle.yaml`. `templates/` в `--all` НЕ входит (проверяется явным путём).
- `--root` — корень репозитория; по умолчанию текущая директория (cwd).
- `--baseline PATH` — JSON с допущенными нарушениями legacy-кнопок; отфильтровывает совпадающие пары (unit_path, code).
- `--write-baseline PATH` — записать baseline из ВСЕХ текущих нарушений и завершиться с кодом 0.
- `--strict` — baseline игнорируется, warning считаются error (гейт приёмки D-08).
- `--json` — только машинный вывод в stdout (без человекочитаемого текста).

Exit-коды: 0 = чисто, 1 = есть нарушения (error; в `--strict` — и warning), 2 = ошибка использования/внутренняя.

Публичные функции модуля (тесты импортируют их напрямую):
```python
@dataclasses.dataclass
class Violation:
    path: str        # POSIX-relpath от root (папка кнопки, .py или bundle.yaml)
    code: str        # "MM001"…
    severity: str    # "error" | "warning"
    line: int | None
    message: str     # русский текст

def check_pushbutton(button_dir, root) -> list[Violation]
def check_script(script_path) -> list[Violation]          # режим сырого скрипта
def check_layouts(root) -> list[Violation]                # орфаны tab/panel layout (MM007)
def iter_pushbuttons(root) -> list[Path]
def load_baseline(path) -> dict
def apply_baseline(violations, baseline) -> list[Violation]
def write_baseline(violations, path) -> None
def main(argv=None) -> int
```

Схема baseline JSON:
```json
{
  "generated": "YYYY-MM-DD",
  "note": "Grandfathered legacy-кнопки. При адаптации кнопки удали её запись.",
  "units": {
    "MM LAB.extension/MM Lab.tab/АРХИТЕКТУРА.panel/IFC_Двери.pushbutton": ["MM001", "MM006"],
    "MM LAB.extension/MM Lab.tab/bundle.yaml": ["MM007"]
  }
}
```

Схема `--json`-вывода:
```json
{"checked": 3, "errors": 5, "warnings": 2,
 "violations": [{"path": "...", "code": "MM001", "severity": "error", "line": 1, "message": "..."}]}
```

Правила этого плана (severity фиксирована):

| Код | Severity | Проверка |
|-----|----------|----------|
| MM000 | error | файл не читается/не парсится `ast.parse` (SyntaxError → нарушение, не traceback) |
| MM001 | error | строка 1 script.py == `#! python3` (чтение с `encoding="utf-8-sig"`) |
| MM002 | error | строка 2 == `# -*- coding: utf-8 -*-` |
| MM003 | error | первые 3 байта файла != `EF BB BF` (UTF-8 BOM запрещён) |
| MM004 | warning | module docstring содержит `Совместимость:` И `Зависимости:` (через `ast.get_docstring`) |
| MM005 | error | в папке кнопки есть `bundle.yaml` с ключами `title:` и `tooltip:` |
| MM006 | error | в папке кнопки есть `README.md` |
| MM007 | error | (а) имя папки кнопки без суффикса `.pushbutton` есть в `layout:` родительского panel-`bundle.yaml` (сравнение после `.strip()`); (б) каждая запись layout (кроме разделителей из 3+ `-` или `>`) имеет папку на диске — иначе орфан, приписывается bundle.yaml; кнопка НЕ внутри `*.panel` (например `templates/`) — правило пропускается |
| MM013 | warning | в папке кнопки нет мусора: `__pycache__/`, `*.pyc`, `.vs/`, `*.csv` |

Парсинг bundle.yaml: PyYAML не использовать — построчный парсер ограниченной схемы (ключ `layout:`, записи `- <имя>`; ключи `title:`/`tooltip:` на верхнем уровне), значения и записи обрезать `.strip()`. Ограничение задокументировать в docstring.
Кодировка вывода: в начале `main` — `sys.stdout.reconfigure(encoding="utf-8")` в try/except (Windows-консоль cp1251/cp866).
