Claude Code — файл .claude/commands/mm-<слаг>.md:
- YAML-frontmatter (файл начинается и заканчивается строкой-разделителем из трёх дефисов) с полями:
  description: "MM LAB: <назначение по-русски>" и, где уместно, argument-hint: "<подсказка>"
- Тело (2–3 строки): «Прочитай файл agents/commands/mm-<слаг>.md и выполни описанную процедуру
  шаг за шагом, соблюдая все гейты и запреты. Аргументы пользователя: $ARGUMENTS»

Gemini CLI — файл .gemini/commands/mm-<слаг>.toml (ПЛОСКОЕ имя файла — дефис в имени = дефис в команде;
подпапка mm/check.toml дала бы команду с двоеточием /mm:check — НЕ использовать):
```toml
description = "MM LAB: <назначение по-русски>"
prompt = """
Прочитай файл agents/commands/mm-<слаг>.md и выполни описанную процедуру шаг за шагом,
соблюдая все гейты и запреты. Аргументы пользователя: {{args}}
"""
```

Kilo Code — файл .kilo/commands/mm-<слаг>.md:
- YAML-frontmatter (между строками-разделителями из трёх дефисов) с полем description: "MM LAB: <назначение>"
- Тело (2 строки): «Прочитай файл agents/commands/mm-<слаг>.md и выполни описанную процедуру
  шаг за шагом, соблюдая все гейты и запреты. Аргументы: всё, что пользователь передал после /mm-<слаг>.»

Слаги (фиксированы D-20): mm-adopt-script, mm-new-button, mm-check, mm-save-session, mm-update-repo, mm-doctor, mm-new-compat.
Каталог адаптеров Claude — именно .claude/commands/ (НЕ .claude/skills/ — там GSD-манифест gsd-file-manifest.json, чужая территория).
