# Конфузор/Диффузор

## Описание

Кнопка анализирует переходы (фитинги с `PartType = Transition`) воздуховодной
сети: сравнивает площади входного и выходного HVAC-коннекторов и записывает
результат в параметр «Конфузор» — 1 для сужающегося перехода (конфузор),
0 для расширяющегося (диффузор).

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`).
2. Сбор фитингов категории `OST_DuctFitting` (`ios_common_helpers.collect_elements`).
3. В одной транзакции для каждого фитинга:
   - пропускается, если у него нет `MEPModel` или `PartType` не читается;
   - пропускается, если `PartType` не равен `Transition`;
   - пропускается, если у него не ровно два HVAC-коннектора
     (`ios_common_helpers.get_hvac_connectors`) или не удаётся определить
     входной/выходной коннектор по `FlowDirectionType`;
   - вычисляются площади коннекторов (`ios_common_helpers.get_connector_area`);
     фитинг пропускается при нулевой или равной площади (в пределах допуска
     `AREA_TOLERANCE = 1e-6`);
   - пропускается, если параметр «Конфузор» недоступен для записи или имеет
     тип хранения, отличный от `Integer`;
   - иначе параметру «Конфузор» присваивается 1 (конфузор — площадь входа
     больше площади выхода) или 0 (диффузор), счётчики обновляются.
4. Итоги (классифицировано / конфузоров / диффузоров / пропущено) выводятся
   в `TaskDialog`.

## Используемые параметры

| Параметр | Назначение |
|----------|------------|
| «Конфузор» / «Confuser» | принимает 1 (конфузор) или 0 (диффузор) по итогам сравнения площадей коннекторов |

Параметр резолвится по локализованным именам «Конфузор»/«Confuser»
(`ios_common_helpers.get_parameter_by_names`) — устойчивого `BuiltInParameter`
для него нет, так как это пользовательский параметр проекта.

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`, `ios_common_helpers`).

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024

## Ограничения

- Параметр «Конфузор» должен существовать в проекте (тип `Integer`,
  доступный для записи) — иначе фитинг молча пропускается и попадает
  в счётчик «Пропущено».
- Обрабатываются только фитинги с ровно двумя HVAC-коннекторами и
  определённым направлением потока (In/Out); фитинги с иным числом
  коннекторов пропускаются.
- Переходы, у которых оба коннектора `Bidirectional` (не подключены к системе
  с рассчитанным потоком), пропускаются намеренно: без направления потока
  «конфузор» и «диффузор» неразличимы — сужение по потоку является
  расширением против него.
- Переход с одинаковой площадью входа и выхода (смена формы без смены
  площади, в пределах `AREA_TOLERANCE`) не классифицируется.

Итоговый диалог показывает разбивку пропусков по причинам — по ней видно,
относится ли пропуск к настройкам модели или к составу семейств.
