# Замена CAD-геометрии

## Описание

Кнопка работает внутри редактора семейств (`.rfa`) и заменяет тяжёлую
DWG-геометрию (импортированные CAD-инстансы) на лёгкие нативные боксы,
сохраняя при этом коннекторы семейства — тип (воздуховод/труба), профиль,
параметры потока и классификации системы переносятся на новую геометрию.
Нужна, чтобы облегчить семейства, собранные поверх импортированного DWG,
без потери работоспособности коннекторов при вставке в проект.

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`).
2. Проверка, что документ — семейство (`doc.IsFamilyDocument`); иначе диалог
   с просьбой открыть `.rfa` и выход.
3. Считывание всех `ConnectorElement` семейства: точка, ориентация, домен
   (HVAC/Piping), профиль, радиус/ширина/высота, классификация системы и
   направление потока — параметры системы и потока читаются через
   `revit_compat.get_parameter` с фолбэком на альтернативный
   `BuiltInParameter`, если основной недоступен.
4. Сбор bounding box'ов геометрии DWG-импортов (по треугольным `Mesh`,
   либо, если их нет, по `BoundingBox` импорта) и отбрасывание боксов,
   полностью вложенных в другие.
5. **Транзакция 1** — создание нативных боксов по bounding box'ам и
   маленьких tiny-экструзий в точках сохранённых коннекторов (нужны как
   носитель грани для нового коннектора).
6. **Транзакция 2** — на каждой tiny-экструзии находится ближайшая по
   нормали грань, на ней создаётся новый `ConnectorElement` того же домена
   и профиля с переносом параметров потока/системы; исходные коннекторы,
   DWG-импорты, их типы (включая `CADLinkType`) и категории импорта
   удаляются.
7. **Транзакция 3** — удаление неиспользуемых элементов (`GetUnusedElements`
   в несколько итераций, либо `PerformanceAdviser` как запасной вариант).
8. Итоговая сводка (коннекторы, боксы, удалённые DWG/типы/категории,
   purge) выводится в `TaskDialog`; при ошибке любой транзакции — откат
   и диалог с текстом ошибки.

## Используемые параметры

| Параметр | Назначение |
|----------|------------|
| `RBS_DUCT_CONNECTOR_SYSTEM_CLASSIFICATION_PARAM` / `RBS_DUCT_CONNECTOR_SYSTEM_TYPE_PARAM` | классификация системы воздуховодного коннектора — читается со старого, пишется на новый |
| `RBS_PIPE_CONNECTOR_SYSTEM_CLASSIFICATION_PARAM` / `RBS_PIPE_CONNECTOR_SYSTEM_TYPE_PARAM` | классификация системы трубного коннектора — читается со старого, пишется на новый |
| `RBS_DUCT_CONNECTOR_FLOW_DIRECTION_PARAM` / `RBS_PIPE_CONNECTOR_FLOW_DIRECTION_PARAM` | направление потока коннектора |
| `CONNECTOR_RADIUS` | радиус круглого коннектора |
| `CONNECTOR_WIDTH` / `CONNECTOR_HEIGHT` | габариты прямоугольного коннектора |

Все параметры читаются/пишутся через `revit_compat.get_parameter`
(канонический pythonnet-совместимый каскад) — прямых вызовов
`get_Parameter` в скрипте нет.

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`).

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024

## Ограничения

- Работает только в редакторе семейств (`.rfa`); в проектном документе
  показывает диалог и завершается без изменений.
- Новый коннектор создаётся только если на tiny-экструзии нашлась грань,
  нормаль которой достаточно совпадает с исходной ориентацией коннектора
  (порог `dot >= 0.5`); иначе коннектор пропускается, это фиксируется
  в логе диалога через счётчик «Коннекторов создано».
- После замены Revit не освобождает память самостоятельно — чтобы файл
  семейства реально уменьшился в размере, нужно выполнить «Сохранить как».
