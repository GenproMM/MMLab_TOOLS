# Доп. расход 1

## Описание

Кнопка устанавливает значение 1 в общесистемный параметр «Доп. расход»
(`RBS_ADDITIONAL_FLOW`) у элементов воздуховодной сети проекта: воздуховодов,
фитингов, арматуры, воздухораспределителей и гибких воздуховодов. Нужна для
задания добавки расхода перед пересчётом или выгрузкой спецификации.

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`).
2. Сбор элементов категорий `OST_DuctCurves`, `OST_DuctFitting`,
   `OST_DuctAccessory`, `OST_DuctTerminal`, `OST_FlexDuctCurves`
   (`ios_common_helpers.collect_additional_flow_elements`).
3. В одной транзакции для каждого элемента: если параметр «Доп. расход»
   доступен для записи, имеет тип `Double` и его текущее значение отличается
   от 1 — параметр устанавливается в 1, счётчик изменённых элементов
   увеличивается.
4. Итоговое количество изменённых элементов выводится в `TaskDialog`.

## Используемые параметры

| Параметр | Назначение |
|----------|------------|
| «Доп. расход» (`RBS_ADDITIONAL_FLOW`) | устанавливается в 1 у элементов воздуховодной сети |

Параметр резолвится по `BuiltInParameter.RBS_ADDITIONAL_FLOW` через
`ios_common_helpers.set_additional_flow_value` (`LookupParameter` по имени
из `ParameterElement`, без строковых литералов в самом скрипте кнопки).

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`, `ios_common_helpers`).

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024

## Ограничения

- Элементы, у которых параметр «Доп. расход» отсутствует, только для чтения
  или имеет иной тип хранения (не `Double`), пропускаются молча — счётчик
  их не учитывает.
