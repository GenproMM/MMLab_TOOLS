# Приточный по классификации

## Описание

Кнопка находит в проекте все классификации систем воздуховодной сети и
позволяет для каждой классификации выбрать одно из трёх действий: включить
параметр «Приточный», выключить его или не менять. Нужна, чтобы массово
разметить принадлежность элементов к приточным/неприточным системам без
ручного назначения параметра поэлементно.

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`).
2. Сбор элементов категорий `OST_DuctFitting`, `OST_DuctAccessory`,
   `OST_DuctTerminal` (`ios_common_helpers.collect_elements`).
3. Для каждого элемента определяется классификация системы
   (`ios_common_helpers.get_system_classification`); уникальные
   классификации собираются в список, для каждой подбирается решение
   по умолчанию (`ios_common_helpers.get_default_supply_flag_decision` —
   распознаёт «приток»/«вытяжку» по названию классификации).
4. Пользователю показывается таблица (WinForms `DataGridView`) со списком
   найденных классификаций и выпадающим списком решений: «Приток»,
   «Не приток», «Не менять». Отмена диалога прерывает команду без изменений.
5. В одной транзакции для каждого элемента: если для его классификации
   выбрано «Приток» или «Не приток», а параметр «Приточный» доступен для
   записи и имеет тип `Integer` — параметр устанавливается в 1 или 0
   соответственно (если значение уже совпадает — элемент не трогается).
   Классификации со значением «Не менять» и элементы без распознанной
   классификации пропускаются.
6. Итоги (изменено / без изменений / пропущено / классификаций в настройке)
   выводятся в `TaskDialog`.

## Используемые параметры

| Параметр | Назначение |
|----------|------------|
| «Приточный» (общесистемный/общий параметр, резолвится по имени) | устанавливается в 1 (приток) или 0 (не приток) у элементов выбранной классификации |

Параметр резолвится по списку известных локализованных имён
(`ios_common_helpers.get_supply_flag_parameter`: «Приточный», «Приток»,
«Supply», «Supply Flag») — стабильного `BuiltInParameter` у него нет, это
пользовательский/общий параметр проекта.

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`, `ios_common_helpers`).

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024

## Ограничения

- Элементы без распознанной классификации системы или с классификацией,
  для которой выбрано «Не менять», не обрабатываются.
- Элементы, у которых параметр «Приточный» отсутствует, только для чтения
  или имеет иной тип хранения (не `Integer`), пропускаются молча — счётчик
  их учитывает как «пропущено».
