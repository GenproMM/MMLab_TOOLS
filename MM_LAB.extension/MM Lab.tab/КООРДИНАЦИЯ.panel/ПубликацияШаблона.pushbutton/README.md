# Публикация Шаблона

## Описание

Кнопка публикует выбранный открытый проект Revit сразу в двух форматах на
диске `G:`: как проект `.rvt` в общую папку RVT и как шаблон `.rte` в папку
публикаций RTE. Публикация идёт через одну временную копию проекта в `%TEMP%`,
поэтому исходный `.rvt` не превращается в шаблон и не теряет рабочие наборы:
копия дважды открывается фоном (с разными настройками отсоединения) и
сохраняется в целевые папки, после чего временные файлы и папки бэкапов
удаляются.

Проект для публикации выбирается в диалоге из списка всех открытых и
сохранённых на диск проектов — работать с активным документом не обязательно.

Год-подпапка публикации `.rte` берётся из версии текущего Revit: на Revit 2024
шаблон уходит в `...\2_RTE\2024`, на 2022 — в `...\2_RTE\2022`. Папка `.rvt`
(`...\1_RVT`) общая, без разбивки по годам.

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`) — возвращает
   версию, из которой собираются маркер имени и год-подпапка `.rte`.
2. Собирается список кандидатов: все открытые документы, которые не являются
   семействами (`IsFamilyDocument`) и загруженными связями (`IsLinked`) и
   сохранены на диск как `.rvt`. Если список пуст — сообщение и выход.
3. Диалог выбора проекта (WinForms, выпадающий список по имени документа).
   Отмена — выход без публикации.
4. Имена целевых файлов:
   - `.rvt` — из имени файла убирается хвост с логином пользователя
     (`_e.ahmedyanova`); маркер `RD_` НЕ добавляется;
   - `.rte` — то же плюс `RD_` перед маркером версии, если его там ещё нет.
     Маркер собирается из версии Revit: 2024 → `R24`, 2020 → `R20`.
5. Выбранный проект сохраняется (`doc.Save()`), в `%TEMP%` создаётся временная
   копия `<имя>_publish_temp.rvt`.
6. Публикация `.rvt`: копия открывается фоном с `DetachAndPreserveWorksets`
   (для совместных моделей) или `DoNotDetach`, для совместных моделей
   выставляется `WorksharingSaveAsOptions.SaveAsCentral = True`, документ
   сохраняется как `<имя>.rvt` с перезаписью.
7. Публикация `.rte`: та же копия открывается фоном заново с
   `DetachAndDiscardWorksets` (для совместных) или `DoNotDetach` и сохраняется
   как `<имя>.rte` с перезаписью.
8. Фоновые документы закрываются в `finally` (каждый — свой), временная копия
   удаляется, из обеих целевых папок убираются файлы `*_temp*`, нумерованные
   `.0001.rte` / `.0001.rvt` и папки `*_backup`.

## Используемые параметры

Параметры Revit кнопка не читает и не пишет — работает только со свойствами
документа (`Title`, `PathName`, `IsWorkshared`, `IsFamilyDocument`) и файловой
системой.

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`). Диалог выбора построен на `System.Windows.Forms` /
`System.Drawing` (`pyrevit.forms` под CPython не работает).

Требуется доступ на запись к обеим сетевым папкам:

- `G:\Общие диски\02_BIM\2_Templates\1_Revit\1_Project\1_RVT`
- `G:\Общие диски\02_BIM\2_Templates\1_Revit\1_Project\2_RTE`

## Ограничения

- Модель не изменяется, транзакция не открывается: `doc.Save()` и `SaveAs`
  выполняются вне транзакции (Revit запрещает их внутри неё).
- Кнопка вызывает `doc.Save()` — несохранённые правки выбранного проекта
  попадут в файл.
- Зачистка целевых папок удаляет из них все файлы с `_temp` в имени,
  нумерованные `.NNNN.rte` / `.NNNN.rvt` и папки `*_backup` — независимо
  от того, кто их создал.
- Маркер `RD_` подставляется только если в имени исходного файла есть маркер
  версии текущего Revit (`R24` на 2024, `R20` на 2020).
- Очистка имени срезает последний сегмент после `_`, состоящий из букв, цифр,
  точек и дефисов. Если логина пользователя в имени нет, срежется то, что
  стоит на его месте (например `Проект_R24` → `Проект`).
- Документы с одинаковым `Title` в списке схлопываются в один пункт.

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024
