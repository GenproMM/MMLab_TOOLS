# Публикация Шаблона

## Описание

Кнопка публикует открытый проект Revit как шаблон `.rte` в общую папку
публикаций на диске `G:`. Публикация идёт через временную копию проекта,
поэтому исходный `.rvt` не превращается в шаблон и не теряет рабочие наборы:
копия открывается фоном с отсоединением от центральной модели, сохраняется
как `.rte`, после чего временные файлы и папки бэкапов удаляются.

Год-подпапка публикации берётся из версии текущего Revit: на Revit 2024
шаблон уходит в `...\2_RTE\2024`, на 2022 — в `...\2_RTE\2022`.

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`) — возвращает
   версию, из которой собирается путь публикации.
2. Проверки документа: открыт проект (не семейство) и сохранён на диск как `.rvt`.
3. Имя шаблона: из имени файла убирается хвост с логином пользователя
   (`_e.ahmedyanova`), и перед маркером версии подставляется `RD_`, если его
   там ещё нет. Маркер собирается из версии Revit: 2024 → `R24`, 2020 → `R20`.
4. Текущий проект сохраняется (`doc.Save()`), рядом с целевой папкой создаётся
   временная копия `<имя>_temp.rvt`.
5. Копия открывается фоном: для совместных моделей — с
   `DetachAndDiscardWorksets`, для одиночных — `DoNotDetach`.
6. Фоновый документ сохраняется как `<имя>.rte` с перезаписью существующего файла.
7. Фоновый документ закрывается, из целевой папки удаляются файлы `*_temp*`,
   нумерованные `.0001.rte` / `.0001.rvt` и папки `*_backup`.

## Используемые параметры

Параметры Revit кнопка не читает и не пишет — работает только со свойствами
документа (`PathName`, `IsWorkshared`, `IsFamilyDocument`) и файловой системой.

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`).

Требуется доступ на запись к сетевой папке
`G:\Общие диски\02_BIM\2_Templates\1_Revit\1_Project\2_RTE`.

## Ограничения

- Модель не изменяется, транзакция не открывается: `doc.Save()` и `SaveAs`
  выполняются вне транзакции (Revit запрещает их внутри неё).
- Кнопка вызывает `doc.Save()` — несохранённые правки текущего проекта
  попадут в файл.
- Зачистка целевой папки удаляет из неё все файлы с `_temp` в имени,
  нумерованные `.NNNN.rte` / `.NNNN.rvt` и папки `*_backup` — независимо
  от того, кто их создал.
- Маркер `RD_` подставляется только если в имени исходного файла есть маркер
  версии текущего Revit (`R24` на 2024, `R20` на 2020).

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024
