# ВОР — Ссылка на лист

## Описание

Плагин автоматически заполняет параметр ссылки на лист (`GP_01_СсылкаНаЛист`)
для спецификации Ведомости Объемов Работ (ВОР). На основе выбранных пользователем
планов этажей собираются элементы и материалы, определяется их расположение на листах,
и в параметр элемента записывается ссылка в формате «см.лист ХХХ, YYY».

## Логика работы

1. Плагин строит иерархическое дерево листов на основе текущей сортировки проекта
   (группировка по параметрам листа: Комплект, Группа, Назначение, Владелец).
2. Пользователю показывается интерактивное окно с деревом: группы → листы → планы этажей.
3. Пользователь выбирает планы этажей для обработки (есть кнопки выделить/снять всё).
4. Для каждого выбранного плана собираются элементы определённых категорий:
   - **Материалы:** стены, перекрытия, крыши, потолки;
   - **Элементы:** двери, окна, обобщённые модели, оборудование, ограждения,
     сантехнические приборы, специальное оборудование.
5. Для каждого элемента проверяются параметры:
   - `GP_01_ВидРаботы` — обязательный параметр (элементы без него пропускаются);
   - `GP_01_Зона` — используется для определения зоны (Подземная / Надземная).
6. Для материалов дополнительно проверяется параметр `GP_01_КодЕдиницыЭкз`.
7. Для каждого элемента определяется лист, на котором размещена его план:
   - Если элемент находится на плане, заполненном на листе, номер листа добавляется в список.
8. Номера листов для каждого элемента форматируются в строку «см.лист XXX, YYY, ZZZ»
   (в естественном порядке сортировки: 1, 2, 3... 9, 10, 11).
9. В одной транзакции записываются значения в параметр `GP_01_СсылкаНаЛист`
   всех обработанных элементов.
10. После завершения выводится отчёт: количество обработанных элементов,
    количество обновленных, время выполнения, список ошибок и элементов с проблемами.

## Параметры элементов и листов

| Параметр | Назначение | Тип |
|----------|-----------|-----|
| `GP_01_СсылкаНаЛист` | Параметр для записи ссылки на листы | String (Output) |
| `GP_01_ВидРаботы` | Вид работы элемента (обязательный) | String (Input) |
| `GP_01_Зона` | Зона расположения (определяет Подземная/Надземная) | String (Input) |
| `GP_01_КодЕдиницыЭкз` | Код единицы для материалов (проверяется) | String |
| `GP_01_КомплектВида` | Групп. листа — приоритет 1 | String |
| `GP_01_ГруппаВида` | Групп. листа — приоритет 2 | String |
| `GP_01_НазначениеВида` | Групп. листа — приоритет 3 | String |
| `GP_01_ВладелецВида` | Групп. листа — приоритет 4 | String |

## Категории обработки

### Материалы (спецификация материалов)
- `OST_Walls` — стены
- `OST_Floors` — перекрытия
- `OST_Roofs` — крыши
- `OST_Ceilings` — потолки

### Элементы (спецификация элементов)
- `OST_Doors` — двери
- `OST_Windows` — окна
- `OST_GenericModel` — обобщённые модели
- `OST_MechanicalEquipment` — механическое оборудование
- `OST_StairsRailing` — ограждения и лестницы
- `OST_PlumbingFixtures` — сантехнические приборы
- `OST_SpecialityEquipment` — специальное оборудование

## Транзакция и обработка ошибок

- Все изменения выполняются в одной транзакции:
  `Заполнение GP_01_СсылкаНаЛист`.
- При возникновении ошибки выполняется `RollBack`, изменения отменяются.
- Элементы, для которых отсутствуют требуемые параметры, пропускаются и выводятся
  в отчёте:
  - Элементы без `GP_01_ВидРаботы`;
  - Элементы без определённой зоны (если значение `GP_01_Зона` не содержит
    текстов «подземн» или «надземн»);
  - Материалы без `GP_01_КодЕдиницыЭкз`.

## Ограничения

- Обрабатываются только те элементы, которые содержат оба параметра: `GP_01_ВидРаботы`
  и `GP_01_Зона`.
- Зона определяется по наличию текстов «подземн» или «надземн» в значении параметра
  `GP_01_Зона` (регистронезависимо). Иные значения игнорируются.
- Параметр должен называться строго `GP_01_СсылкаНаЛист` (другие имена не обработаны).
- На очень больших моделях сбор элементов по всем категориям может влиять на скорость.
- Диалоговое окно требует интерактивного выбора планов (нет режима пакетной обработки).

## Интерфейс

При запуске открывается диалоговое окно **Выбор видов для обработки** с:

- **Иерархическое дерево** — группы листов (слева направо: Комплект → Группа → Назначение → Владелец),
  листы (номер и имя), планы этажей, размещённые на каждом листе.
- **Чекбоксы** — пользователь отмечает планы для обработки.
- **Кнопки:**
  - **Выделить всё** — отметить все планы в дереве.
  - **Снять выделение** — отменить всё.
  - **Выполнить** — запустить обработку выбранных планов.
  - **Отмена** — закрыть окно без изменений.

После выполнения показывается диалог с отчётом:

- Обработано элементов (всего).
- Обновлено элементов (с записью параметра).
- Время выполнения в секундах.
- Список элементов с проблемами (без зоны, без вида работы, без кода единицы).
- Ошибки при записи (если были).

## Результат работы

Пример выходной строки в параметре `GP_01_СсылкаНаЛист`:

```
см.лист АЗ-01, АЗ-02, АЗ-03
```

Если элемент находится только на одном листе:

```
см.лист АЗ-01
```

Номера листов сортируются в естественном порядке (1 < 2 < 10, а не 1 < 10 < 2).
