# IFC Перекрытия

## Описание

Кнопка классифицирует перекрытия проекта по системе МССК и заполняет общие
параметры `GP_01_КодКлассифМССК` и `GP_01_ИмяКлассифМССК` значениями
`ЭЛ 30 10 40` / «Перекрытие». Обрабатываются только те экземпляры перекрытий,
типоразмеры которых пользователь отметил в диалоге. Нужна для подготовки модели
к выгрузке в IFC с корректной классификацией перекрытий — вместе с кнопками
`IFC_Двери` и `IFC_Окна`.

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`).
2. Сбор всех типоразмеров перекрытий (`FloorType`); фундаментные плиты
   (`IsFoundationSlab`) из списка исключаются.
3. Диалог множественного выбора типоразмеров (WinForms `CheckedListBox`),
   список отсортирован по имени типоразмера.
4. Сбор экземпляров перекрытий категории `OST_Floors` и фильтрация по выбранным
   типоразмерам; подтверждение количества обрабатываемых элементов.
5. В одной транзакции каждому перекрытию пишутся код `ЭЛ 30 10 40`
   и имя «Перекрытие». Ошибки записи (параметр не найден / только для чтения)
   выводятся в окно pyRevit по ElementId.
6. Итог — сводка в окне pyRevit и диалог с числом заполненных и пропущенных
   перекрытий.

## Используемые параметры

| Параметр | GUID | Назначение |
|----------|------|------------|
| `GP_01_КодКлассифМССК` | `4df18cfa-3e5b-4e84-aef6-5ac3385a7d4f` | запись кода классификации МССК перекрытия |
| `GP_01_ИмяКлассифМССК` | `91f5b762-e361-462c-8611-3d952be1777b` | запись имени классификации МССК перекрытия |
| Имя типоразмера (`SYMBOL_NAME_PARAM`) | — | чтение при формировании списка выбора |

Общие параметры пишутся по GUID через `revit_compat.get_shared_parameter`;
встроенный параметр имени типоразмера читается через `revit_compat.get_parameter`
с `BuiltInParameter.SYMBOL_NAME_PARAM`.

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`, `revit_ui_helpers`). Окно вывода — `pyrevit.script`.

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024

## Ограничения

- Классификация фиксированная: всем выбранным перекрытиям пишется один и тот же
  код `ЭЛ 30 10 40` / «Перекрытие». Разделение по назначению перекрытия
  не выполняется — отбор целиком на стороне пользователя (выбор типоразмеров).
- Перекрытия, у которых нет общих параметров `GP_01_*` (не загружен ФОП
  GENPRO), пропускаются с сообщением в окне вывода; транзакция при этом
  не откатывается.
- Фундаментные плиты не показываются в списке выбора и не обрабатываются.
