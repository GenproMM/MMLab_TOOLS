# Кривые панели — запись радиуса криволинейных стен

## Описание

Плагин записывает радиус криволинейной стены в параметр экземпляров панелей витража,
привязанных к этой стене. Радиус берётся из геометрии осевой линии стены,
если она является дугой.

Сценарий полезен для автоматического заполнения параметра `GP_16_Радиус`
у загружаемых панелей, размещённых на криволинейных участках.

## Логика работы

1. Получается текущий выбор пользователя в модели.
2. Если в выборе есть элементы, берутся только стены из выбранных элементов.
3. Если выбор пустой, собираются все стены проекта.
4. Для каждой стены проверяется кривая расположения (`LocationCurve`).
5. Если кривая является дугой (`Arc`), считывается её радиус.
6. Для найденной криволинейной стены собираются экземпляры семейств (`FamilyInstance`).
7. Среди экземпляров ищутся элементы, у которых `Host` совпадает с текущей стеной.
8. У найденных экземпляров проверяется параметр `GP_16_Радиус`.
9. Если параметр существует и не только для чтения, в него записывается радиус стены.
10. По завершении показывается отчёт: количество криволинейных стен и обработанных панелей.

## Параметры и категории

Используются следующие данные Revit:

| Элемент / параметр | Назначение |
|--------------------|------------|
| `OST_Walls` | Сбор стен-кандидатов для обработки |
| `LocationCurve` + `Arc` | Определение криволинейной стены и получение радиуса |
| `FamilyInstance.Host` | Поиск панелей, привязанных к конкретной стене |
| `GP_16_Радиус` | Параметр экземпляра панели для записи радиуса |

## Транзакция и обработка ошибок

- Изменения выполняются в одной транзакции:
  `Запись радиуса стен в загружаемые панели витража`.
- При ошибке выполняется `RollBack`, после чего выводится сообщение с текстом ошибки.
- При успешном завершении выводится итоговая статистика.

## Зависимости

Внешних зависимостей нет. Используются модули Revit API:

- `Autodesk.Revit.DB`
- `Autodesk.Revit.UI`
- `RevitServices`

## Совместимость

Скрипт использует базовые API-классы (`Wall`, `Arc`, `FamilyInstance`, `Transaction`),
которые доступны в Revit 2020 / 2022 / 2024.

Версионно-зависимые типы (`UnitTypeId`, `SpecTypeId` и т.д.) не используются.

## Ограничения

- Обрабатываются только стены с осью-дугой. Прямые и иные типы кривых пропускаются.
- Параметр должен называться строго `GP_16_Радиус`.
- Запись выполняется только в редактируемые (не read-only) параметры.
- Проверяются все экземпляры семейств в проекте, после чего фильтруются по `Host`.
  На очень больших моделях это может влиять на скорость выполнения.

## Результат работы

После запуска показывается диалог с итогом:

- количество обнаруженных криволинейных стен;
- количество панелей, в которые записан радиус.
