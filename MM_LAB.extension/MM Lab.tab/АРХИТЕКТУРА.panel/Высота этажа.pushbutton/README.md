# Высота этажа — расчёт межуровневой высоты для помещений

## Описание

Плагин рассчитывает полезную высоту этажа между соседними уровнями и записывает
результат в параметры уровня и помещений.

Для каждого уровня берётся разница отметок до следующего уровня и вычитается
толщина ближайшего перекрытия верхнего уровня. Итоговая высота используется для
автоматического заполнения параметра `GP_16_Высота` у уровня и параметра
`Высота этажа` у помещений на этом уровне.

## Логика работы

1. Собираются все уровни проекта (`Level`).
2. Уровни сортируются по отметке (`Elevation`) в порядке возрастания.
3. Для каждого уровня (кроме последнего) определяется следующий уровень.
4. Вычисляется межуровневая высота: отметка следующего уровня минус отметка текущего.
5. На следующем уровне ищется ближайшее перекрытие (`Floor`) с минимальным смещением
   относительно отметки уровня.
6. Толщина перекрытия читается из параметра `Thickness`; если параметр недоступен,
   толщина суммируется по слоям `CompoundStructure`.
7. Итоговая высота этажа рассчитывается как:
   межуровневая высота - толщина перекрытия.
8. Для последнего уровня принимается значение 0.
9. Значение записывается в параметр уровня `GP_16_Высота`.
10. То же значение копируется в параметр `Высота этажа` у всех помещений на текущем уровне.
11. После обработки выводится отчёт по уровням в метрах (с округлением до 0.001 м).

## Параметры и категории

Используются следующие данные Revit:

| Элемент / параметр | Назначение |
|--------------------|------------|
| `Level.Elevation` | Расчёт высоты между соседними уровнями |
| `FLOOR_HEIGHTABOVELEVEL_PARAM` | Уточнение положения перекрытия относительно уровня |
| `Thickness` / `CompoundStructure` | Получение толщины перекрытия |
| `GP_16_Высота` | Запись итоговой высоты в параметр уровня |
| `OST_Rooms` + `Высота этажа` | Запись итоговой высоты в параметры помещений |

## Транзакция и обработка ошибок

- Изменения выполняются в одной транзакции:
  `Запись высот между уровнями и копирование в помещения`.
- При ошибке выполняется `RollBack`, после чего показывается сообщение с текстом ошибки.
- Если уровни не найдены, скрипт останавливается с сообщением.
- Если у уровня недоступен параметр `GP_16_Высота`, выводится предупреждение по этому уровню.

## Зависимости

Внешних зависимостей нет. Используются модули Revit API:

- `Autodesk.Revit.DB`
- `Autodesk.Revit.UI`
- `RevitServices`

## Совместимость

Скрипт использует базовые API-классы (`Level`, `Floor`, `Transaction`, `BuiltInParameter`),
которые доступны в Revit 2020 / 2022 / 2024.

Версионно-зависимые типы (`UnitTypeId`, `SpecTypeId` и т.д.) не используются.

## Ограничения

- Для расчёта используется только одно ближайшее перекрытие на следующем уровне.
- Если на следующем уровне нет подходящего перекрытия, толщина принимается равной 0.
- Параметры должны называться строго `GP_16_Высота` (у уровня) и `Высота этажа` (у помещения).
- Запись выполняется только в редактируемые (не read-only) параметры.
- Последнему уровню всегда присваивается значение 0.

## Результат работы

После запуска показывается диалог с текстовым отчётом:

- список пар уровней;
- межуровневая высота, толщина перекрытия и итоговая высота (в метрах);
- отдельная строка для последнего уровня со значением 0 м.
