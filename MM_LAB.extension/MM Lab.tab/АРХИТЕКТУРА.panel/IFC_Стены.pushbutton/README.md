# IFC Стены

## Описание

Кнопка классифицирует стены проекта по системе МССК и заполняет общие параметры
`GP_01_КодКлассифМССК` и `GP_01_ИмяКлассифМССК`. В отличие от `IFC_Двери`,
`IFC_Окна` и `IFC_Перекрытия`, где код один для всех выбранных элементов, стена
попадает в одну из четырёх категорий, и код зависит от категории:

| Категория | Код МССК | Имя МССК |
|-----------|----------|----------|
| Наружные стены (префикс `НС_`) | `ЭЛ 30 10 60` | Фасад |
| Стены `ВС_` толще 200 мм | `ЭЛ 30 10 15` | Стена |
| Перегородки, зашивки, короба, экраны | `ЭЛ 30 10 20` | Перегородка |
| Отделка стен (накладка до 100 мм) | `ЭЛ 30 26` | Отделка стен |

Обрабатываются только те экземпляры стен, типоразмеры которых пользователь
отметил в диалоге. Витражи (`WallKind.Curtain`) не показываются в списке и не
обрабатываются. Нужна для подготовки модели к выгрузке в IFC с корректной
классификацией стен.

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`).
2. Сбор всех типоразмеров стен (`WallType`); витражи исключаются.
3. Диалог множественного выбора типоразмеров (WinForms `CheckedListBox`),
   список отсортирован по имени типоразмера.
4. Сбор экземпляров стен (`Wall`, без витражей), фильтрация по выбранным
   типоразмерам, подтверждение количества анализируемых стен.
5. **Этап 1 — первичная классификация** каждой стены, первое сработавшее
   правило побеждает:
   - имя типоразмера начинается на `НС_` → Фасад;
   - префикс `ВС_` (в русской и английской раскладке) и толщина > 205 мм → Стена;
   - в имени типоразмера есть «зашив» / «фальш» / «короб» / «инстал» / «экран»
     → Перегородка (зашивка);
   - BoundingBox стены примыкает к сантехприбору (`OST_PlumbingFixtures`,
     допуск 0.5 фута в плане) → Перегородка (зашивка);
   - толщина ≤ 125 мм и середина стены попадает в помещение мокрой зоны
     (по имени помещения: «с/у», «санузел», «ванн», «туалет», «душ», «санитар»)
     → Перегородка (зашивка);
   - стена определена как перегородка (см. ниже) → Перегородка;
   - стена определена как отделка (см. ниже) → Отделка стен.
6. **Этап 2 — цепное «заражение» по примыканиям** (до 10 итераций): ещё
   не классифицированная стена, чей BoundingBox касается уже найденной,
   наследует её категорию, если проходит по толщине — ≤ 130 мм для зашивки,
   ≤ 150 мм для перегородки, ≤ 100 мм для отделки.
7. В одной транзакции каждой классифицированной стене пишутся код и имя МССК
   её категории. Ошибки записи (параметр не найден / только для чтения)
   выводятся в окно pyRevit по ElementId; такая стена считается пропущенной.
8. Итог — сводка по категориям в окне pyRevit и диалог с числом заполненных,
   пропущенных и не классифицированных стен.

### Признак перегородки

Стена считается перегородкой, если выполнено любое из:

- префикс `ВС_`, толщина ≤ 205 мм, в имени типа нет «несущ» / «bearing»;
- толщина ≤ 205 мм, в слоях типоразмера найден материал перегородки
  (ГКЛ/ГВЛ/гипс, ПГП, газобетон/пенобетон/силикат, блок, кирпич, дерево, ДСП,
  МДФ, стекло, фибролит и т. п.), и стена не наружная;
- толщина ≤ 150 мм, стена не наружная, в имени типа нет «несущ» / «bearing»
  и имя не начинается на `нс_`.

### Признак отделки стен

Толщина ≤ 100 мм, стена не наружная, не перегородка, её BoundingBox в плане
перекрывается с другой стеной более чем на половину меньшей площади (или совпадает
по высоте), и помещение определено только с одной стороны.

### Признак наружной стены

Проверяется по порядку: префикс `ВС_` → не наружная; префикс `нс_` или «наруж»
в имени типоразмера → наружная; функция типоразмера `WallFunction.Exterior`
→ наружная; помещение определено только с одной стороны стены → наружная.

## Используемые параметры

| Параметр | GUID | Назначение |
|----------|------|------------|
| `GP_01_КодКлассифМССК` | `4df18cfa-3e5b-4e84-aef6-5ac3385a7d4f` | запись кода классификации МССК стены |
| `GP_01_ИмяКлассифМССК` | `91f5b762-e361-462c-8611-3d952be1777b` | запись имени классификации МССК стены |
| Имя типоразмера (`SYMBOL_NAME_PARAM`) | — | чтение при формировании списка выбора и при классификации |
| Имя помещения (`ROOM_NAME`) | — | чтение при определении мокрой зоны |

Общие параметры пишутся по GUID через `revit_compat.get_shared_parameter`;
встроенные параметры читаются через `revit_compat.get_parameter`
с `BuiltInParameter`. Толщина типоразмера переводится в миллиметры
через `revit_compat.convert_from_internal`.

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`, `revit_ui_helpers`). Окно вывода — `pyrevit.script`.

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024

## Ограничения

- Классификация эвристическая: опирается на соглашение об именах типоразмеров
  (`НС_`, `ВС_`), пороги толщины и геометрию BoundingBox. На модели с другим
  неймингом результат нужно проверять глазами.
- Пороги толщины взяты 205 / 150 / 130 / 125 / 100 мм — 205 вместо 200 — запас
  на погрешность перевода единиц.
- Примыкание считается по BoundingBox с допуском 0.5 фута (≈152 мм), а не по
  реальной геометрии: возможны ложные срабатывания на плотно расположенных
  стенах.
- Стены, не попавшие ни в одну категорию, не обрабатываются — их число
  показывается в итоговом диалоге.
- Стены без общих параметров `GP_01_*` (не загружен ФОП GENPRO) пропускаются
  с сообщением в окне вывода; транзакция при этом не откатывается.
- Помещения читаются перебором всех фаз проекта: берётся первая фаза, в которой
  помещение с этой стороны стены определено.
