# IFC Двери

## Описание

Кнопка классифицирует двери проекта по системе МССК и заполняет общие
параметры `GP_01_КодКлассифМССК` и `GP_01_ИмяКлассифМССК`. Тип двери
определяется автоматически по назначению помещений с обеих сторон двери
(`FromRoom` / `ToRoom`) и по имени семейства / типа элемента. Отдельно
распознаются ворота и люки. Нужна для подготовки модели к выгрузке в IFC
с корректной классификацией дверных проёмов.

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`).
2. Сбор всех экземпляров дверей категории `OST_Doors`.
3. Группировка дверей по имени семейства и выбор семейств для обработки
   в диалоге множественного выбора (WinForms).
4. Подтверждение количества обрабатываемых дверей.
5. В одной транзакции для каждой двери:
   - если это ворота — код `ЭЛ 30 18 20`, имя «Ворота»;
   - если это люк — код `ЭЛ 30 18 50`, имя «Люки»;
   - иначе — назначение помещений с обеих сторон нормализуется
     (Квартиры / МОП / Наружу) и по паре значений подбирается код и имя
     (межкомнатная / входная / дверь).
6. Итоговый отчёт по каждой двери выводится в окно pyRevit; в конце —
   сводка и предложение закрыть окно результатов.

## Используемые параметры

| Параметр | GUID | Назначение |
|----------|------|------------|
| `GP_01_КодКлассифМССК` | `4df18cfa-3e5b-4e84-aef6-5ac3385a7d4f` | запись кода классификации МССК двери |
| `GP_01_ИмяКлассифМССК` | `91f5b762-e361-462c-8611-3d952be1777b` | запись имени классификации МССК двери |
| `GP_23_Назначение` | `0b3dbc34-30a7-4278-b1c5-8ba8819f9db4` | чтение назначения помещения (с обеих сторон двери) |
| `Модель` (`ALL_MODEL_MODEL`) | — | чтение при распознавании ворот |

Общие параметры читаются и пишутся по GUID через
`revit_compat.get_shared_parameter`; встроенный параметр «Модель» —
через `revit_compat.get_parameter` с `BuiltInParameter.ALL_MODEL_MODEL`.

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`, `revit_ui_helpers`). Окно вывода — `pyrevit.script`.

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024

## Ограничения

- Классификация опирается на параметр `GP_23_Назначение` у помещений;
  если помещения по обе стороны двери не заданы, дверь получает базовый
  код `ЭЛ 30 18 30` («Дверь»).
- Распознавание ворот и люков — эвристическое (по вхождению слов «ворот»,
  «люк», «технич» в имя семейства / типа / параметр «Модель»).
