# IFC Окна

## Описание

Кнопка классифицирует окна проекта по системе МССК и заполняет общие
параметры `GP_01_КодКлассифМССК` и `GP_01_ИмяКлассифМССК`. Отдельно
распознаются балконные блоки — по имени семейства (вхождение «бблок»),
по параметру «Модель» (вхождение «балкон») и по имени типа. Все прочие
элементы получают код обычного окна. Нужна для подготовки модели к
выгрузке в IFC с корректной классификацией оконных проёмов.

## Логика работы

1. Гейт версии Revit (`revit_compat.require_supported_version`).
2. Сбор всех экземпляров окон категории `OST_Windows`.
3. Группировка окон по имени семейства и выбор семейств для обработки
   в диалоге множественного выбора (WinForms).
4. Подтверждение количества обрабатываемых окон.
5. В одной транзакции для каждого окна:
   - если это балконный блок — код `ЭЛ 30 18 09`, имя «Балконный блок»;
   - иначе — код `ЭЛ 30 18 40`, имя «Окно».
6. Итоговый отчёт по каждому окну выводится в окно pyRevit; в конце —
   сводка и предложение закрыть окно результатов.

## Используемые параметры

| Параметр | GUID | Назначение |
|----------|------|------------|
| `GP_01_КодКлассифМССК` | `4df18cfa-3e5b-4e84-aef6-5ac3385a7d4f` | запись кода классификации МССК окна |
| `GP_01_ИмяКлассифМССК` | `91f5b762-e361-462c-8611-3d952be1777b` | запись имени классификации МССК окна |
| `Модель` (`ALL_MODEL_MODEL`) | — | чтение при распознавании балконного блока |

Общие параметры читаются и пишутся по GUID через
`revit_compat.get_shared_parameter`; встроенный параметр «Модель» —
через `revit_compat.get_parameter` с `BuiltInParameter.ALL_MODEL_MODEL`.

## Зависимости

Внешних зависимостей нет. Общие функции — в `MM_LAB.extension/lib`
(`revit_compat`, `revit_ui_helpers`). Окно вывода — `pyrevit.script`.

## Совместимость

- Revit 2020
- Revit 2022
- Revit 2024

## Ограничения

- Распознавание балконных блоков — эвристическое (по вхождению «бблок»
  в имя семейства, «балкон» в параметр «Модель» экземпляра/типа или в
  имя типа). Всё, что не опознано как балконный блок, классифицируется
  как обычное окно.
