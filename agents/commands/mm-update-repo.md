# /mm-update-repo — безопасное обновление репозитория (fetch + ff-only pull)

Единственный разрешённый способ обновления рабочей копии: `git fetch` +
`git pull --ff-only` при ЧИСТОМ дереве. Никаких деструктивных команд —
при любом конфликте состояния решает человек.

## Аргументы

Нет. Команда всегда работает с текущей веткой и `origin`.

## Процедура

1. **Проверь чистоту дерева:**

   ```bash
   git -c core.quotepath=false status --porcelain
   ```

   Если вывод НЕ пуст — СТОП: покажи пользователю список изменённых файлов
   и предложи сначала выполнить `/mm-save-session` (зафиксировать работу
   коммитом) либо дождись явного решения пользователя, что делать
   с изменениями. Продолжать обновление с грязным деревом запрещено.

2. **Забери обновления с сервера:**

   ```bash
   git fetch origin
   ```

3. **Обнови текущую ветку только fast-forward:**

   ```bash
   git pull --ff-only
   ```

4. **Если ff-only невозможен** (git сообщает о расхождении истории —
   «Not possible to fast-forward») — СТОП: покажи пользователю

   ```bash
   git status
   git log --oneline -5 HEAD..origin/<ветка>
   ```

   и объясни, что локальная и удалённая истории разошлись. Как сводить
   (merge, rebase, что-то ещё) — решает человек; сама процедура ничего
   не сливает и не перезаписывает.

5. **Сообщи итог:** обновлено до <хеш/число коммитов> или «уже актуально».
   Если в подтянутых изменениях затронуты `MM LAB.extension/` или её `lib/` —
   напомни сделать pyRevit Reload (или перезапустить Revit), иначе Revit
   продолжит выполнять старый код кнопок.

## Гейты и запреты

- **Единственный способ обновления — `git fetch origin` + `git pull --ff-only`.**
- **При грязном дереве — остановка** (шаг 1): никакие stash/checkout/discard
  без явного решения пользователя.
- **Запрещены без явного запроса пользователя:** `git reset --hard`,
  `git clean`, `git checkout --force` (и `checkout -- <путь>` для отбрасывания
  чужих правок), `git rebase`. Эти команды уничтожают локальную работу.
- Кириллические пути — статус только через `git -c core.quotepath=false`.

## Финал

Сообщи пользователю:

- итог: обновлено (до какого коммита, сколько новых) / уже актуально /
  остановлено (грязное дерево или расхождение истории — и что делать дальше);
- напоминание про pyRevit Reload, если менялись `MM LAB.extension` или `lib`.
